# فونت‌های ریوان سفر

- **پینار FD** (`pinar/`): نسخهٔ **Pinar-FD** (Farsi Digits instead Latin) — فقط برای **عنوان‌ها**. فایل‌ها از زیپ خریداری‌شدهٔ `Pinar_Pro.zip` (لایسنس‌دار، خرید از fontamin.com) استخراج شده‌اند؛ از همین منبع کپی شوند، نه از سایت متفرقه.
- **وزیرمتن** (`vazirmatn/`): فقط برای **متن بدنه**.

قانون مسعود: عنوان‌ها همیشه پینار، متن معمولی وزیرمتن، اعداد همه‌جا فارسی.
