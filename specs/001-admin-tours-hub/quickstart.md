# Quickstart: Verifying Tour Management Hub

1. Run Next.js: `npm run dev`
2. Open `http://localhost:3000/admin/tours`
3. Verify that the 5-tab Tour Hub bar is active:
   - لیست تورها
   - درخواست‌های رزرو تور
   - مقصدها و شهرها
   - مبدأها
   - هتل‌ها
4. Confirm clicking any tab keeps you inside the Tour Hub experience with zero page breakage.
